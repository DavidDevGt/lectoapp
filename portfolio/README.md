## 🎯 Propósito del Directorio

Esta carpeta contiene una **landing page de alto impacto visual e interactivo**, desarrollada específicamente para exhibir **LectoApp** ante reclutadores técnicos, directores de tecnología (CTOs) e inversionistas educativos.

---

## 🚀 Características de la Landing Page

* **Diseño Moderno & Premium:** Construida con HTML5 semántico, Vanilla CSS estructurado y JavaScript modular sin sobrecargar dependencias innecesarias.
* **Secciones Clave del Proyecto:**
  1. **Hero Section:** Propuesta de valor, contadores animados de impacto e insignias de calidad.
  2. **El Problema Educativo:** Radiografía de la brecha de comprensión lectora en la región.
  3. **Los 3 Componentes del Sistema:** Exposición de la API REST, el Panel Admin y la App Móvil con capturas de pantalla y diagramas de arquitectura.
  4. **Stack Tecnológico:** Grilla de tecnologías clasificadas por rol (Node.js, React, React Native, Prisma, PostgreSQL, Docker, Ollama).
  5. **Garantía de Calidad:** Métricas de las 464 pruebas automatizadas, testing de accesibilidad WCAG y cobertura.
  6. **Llamado a la Acción (CTA) y Contacto:** Enlaces listos para conectar con el perfil de GitHub y correo del autor.

---

## 💻 Cómo Visualizarla o Integrarla

### 1. Visualización Local Inmediata
Simplemente abre `portfolio/index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari). No requiere ningún servidor local ni proceso de compilación previo.

### 2. Despliegue en Servicios Estáticos
Puedes desplegar esta carpeta de forma independiente en plataformas como:
* **GitHub Pages:** Asignando la carpeta `/portfolio` como fuente de publicación.
* **Vercel / Netlify / Cloudflare Pages:** Apuntando el directorio raíz a `portfolio`.
